Machine Learning-based diabetes risk prediction system using Logistic Regression, Random Forest, and SVM to enable early detection and healthcare decision support.

# 🩺 Gluco Risk Analyzer

## Overview

Gluco Risk Analyzer is a Machine Learning-based healthcare application that predicts the likelihood of diabetes using patient health parameters such as Glucose Level, BMI, Insulin, Blood Pressure, Age, and Diabetes Pedigree Function.

The project leverages multiple machine learning algorithms to analyze medical data and provide early diabetes risk assessment, helping support preventive healthcare and informed decision-making.

## Features

* Diabetes risk prediction using Machine Learning
* Data preprocessing and feature engineering
* Multiple model comparison
* Performance evaluation using Accuracy, Precision, and Recall
* Visual performance analysis using graphs and charts
* Healthcare recommendations for high-risk patients

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Machine Learning Models

* Logistic Regression
* Random Forest Classifier
* Support Vector Machine (SVM)

## Dataset Features

* Glucose Level
* Blood Pressure
* BMI
* Insulin
* Pregnancies
* Diabetes Pedigree Function
* Age

## Results

The models were evaluated using:

* Accuracy
* Precision
* Recall

Among the tested algorithms, **Random Forest** achieved the best overall performance and was selected as the final prediction model.
